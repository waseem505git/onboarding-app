# Survival Guide — Source Intake Manifest Template (Stage A.1)

**Status:** Stage A.1 deliverable — a blank record template. This file
must not contain any real source content, owner names, dates, or paths
until someone actually exports a file into `local-source-materials/`
and fills in a copy of the record below for it.

## Purpose

Every file placed under `local-source-materials/` must have exactly one
corresponding intake record (copy the template block below, append it
to this file or to a tracked log of your choosing — the record itself
is metadata *about* the file, not the file's content, so it is safe to
keep in a tracked document even though the file itself is not).

## How to use

1. Export the file from its approved SharePoint location (or confirm it
   is one of the two named local instruction files) per
   `docs/survival-guide-required-source-checklist.md`.
2. Place it under the matching `local-source-materials/<subfolder>/`.
3. Copy the blank record template below, fill in every field you can
   truthfully complete, and leave the rest blank — **never guess**.
4. Do not set "Approved for Stage B analysis" to yes until the
   confidential-data review is complete and a reviewer has signed off.

## Blank record template (copy this block per file)

```
### Record: <local file name>

- Local file name:
- Original file name:
- Source system: (e.g. SharePoint / Groups Instruction library / Yield
  Knowledge Base / DREAM-FE / Signal Management / Pilot Management /
  local instruction file)
- Exact SharePoint site:
- Exact SharePoint folder:
- Document owner: (leave blank unless explicitly stated in the source
  itself or its SharePoint metadata — do not infer)
- Last modified date: (leave blank unless explicitly available from the
  source's own metadata)
- Export date:
- Exported by:
- Intended terminology/topic scope: (which term(s) from
  docs/survival-guide-core-term-review.md or which daily-work topic
  from docs/survival-guide-required-source-checklist.md this is meant
  to support)
- Stable knowledge or procedure: (stable / procedural / mixed /
  unclassified)
- Confidential-data review completed: (yes / no)
- Approved for Stage B analysis: (yes / no — must be "no" until the
  confidential-data review above is "yes" and a reviewer is named)
- Reviewer:
- Notes:
```

## Field definitions

| Field | Definition |
|---|---|
| Local file name | The exact file name as saved under `local-source-materials/` |
| Original file name | The file name as it existed in SharePoint/source system, if different |
| Source system | Which mandated source (per the access report) this came from |
| Exact SharePoint site | The specific site URL/name — not a guess or generic reference |
| Exact SharePoint folder | The specific folder path within that site |
| Document owner | Only filled in if the source itself or its metadata explicitly states an owner — never inferred from author guesses |
| Last modified date | Only filled in if explicitly available from the source's own metadata |
| Export date | The date this file was exported from SharePoint to local disk |
| Exported by | The person who performed the export |
| Intended terminology scope | Which term(s)/topic(s) this file is expected to support — a plan, not a guarantee it will |
| Stable knowledge or procedure | Reviewer's classification once the content has actually been read |
| Confidential-data review completed | Whether the file has been checked against `docs/survival-guide-privacy-review.md`'s gate |
| Approved for Stage B analysis | The explicit go/no-go gate — set only after every other required field is complete |
| Reviewer | Named person who completed the confidential-data review and approval |
| Notes | Anything else relevant — conflicts with other sources, partial coverage, concerns, etc. |
